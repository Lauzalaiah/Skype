Il n'y a pas de version sur l'App Store : y publier demande un compte développeur payant et la validation d'Apple. À la place, l'application s'installe depuis le navigateur, et le résultat est le même à l'usage.

Les questions que tout le monde pose

Est-ce le vrai Skype ? Microsoft est-il derrière ?

Non, et c'est important. Skype Reborn est une recréation indépendante, faite par un fan, écrite de zéro. Il n'y a aucun lien, aucune affiliation et aucun partenariat avec Microsoft ni avec les équipes de Skype. Le nom « Skype » est une marque de Microsoft, employée ici uniquement pour désigner le logiciel d'origine dont ce projet s'inspire.

Pourquoi Windows dit-il que le fichier est dangereux ?

Parce qu'il n'est pas signé. Un certificat de signature de code coûte plusieurs centaines d'euros par an ; ce projet est gratuit et sans revenu. SmartScreen affiche donc l'avertissement réservé aux éditeurs qu'il ne connaît pas — le même que pour n'importe quel petit logiciel indépendant. « Informations complémentaires » puis « Exécuter quand même ».

Puis-je parler avec quelqu'un qui utilise le vrai Skype ?

Non. Les deux réseaux sont totalement séparés : ce projet ne se connecte à aucun service de Microsoft. Vos correspondants doivent utiliser la même installation que vous, sur le même serveur.

Où sont stockées mes conversations ?

Dans votre dossier utilisateur — %APPDATA%\Skype\data sous Windows, ~/Library/Application Support/Skype sous macOS, ~/.config/Skype sous Linux. Ce dossier contient tout : sauvegardez-le, et vous avez sauvegardé votre Skype.

Faut-il payer quelque chose ?

Non. Le logiciel est gratuit, sans publicité et sans abonnement. Le « crédit Skype » reconstruit dans l'application est une reproduction de l'interface d'origine : aucun paiement réel n'a lieu, et aucun appel n'est réellement passé vers le réseau téléphonique.

Ça marche sans connexion Internet ?

L'application de bureau démarre et fonctionne sans Internet : elle embarque son propre serveur, sur votre machine. Pour parler à quelqu'un d'autre, en revanche, il faut évidemment un réseau qui relie vos deux machines — le vôtre, ou Internet si vous hébergez le serveur en ligne.

Comment le désinstaller ?

Comme n'importe quel programme : Paramètres › Applications sous Windows, ou la corbeille sous macOS. Le dossier de données n'est pas supprimé automatiquement — vos conversations survivent à une réinstallation, et vous pouvez l'effacer à la main si vous le souhaitez.

Puis-je héberger le serveur pour ma famille ?

Oui, c'est l'usage prévu. Une machine, Node.js 18, et node server/index.js — aucune dépendance à installer. Il faut ensuite un certificat HTTPS pour que les navigateurs autorisent le micro et la caméra. La marche à suivre complète est dans la documentation d'hébergement.
